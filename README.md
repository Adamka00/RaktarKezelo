# 📦 Raktárkezelő Rendszer (ProOktatás Projekt)

Ez egy C# nyelven íródott raktárkezelő alkalmazás, amely a **ProOktatás Full-stack tanfolyamának** keretein belül készül. A projekt célja a C# nyelv alapjainak, az OOP elveknek és a Windows Forms keretrendszernek a bemutatása.

## 🚀 Fejlesztési terv
A projekt két szakaszban valósul meg:
1. **Konzolos prototípus:** Az üzleti logika (mentés, betöltés, listázás) kidolgozása.
2. **WinForms GUI:** Felhasználóbarát grafikus felület kialakítása (Windows környezetben).

## 🛠 Alkalmazott technológiák és elvek
- **Nyelv:** C# (.NET 8)
- **Fejlesztőkörnyezet:** JetBrains Rider (macOS)
- **OOP alapelvek:** Egységbe zárás (Encapsulation), Öröklődés (Inheritance), Polimorfizmus (Polymorphism)
- **S.O.L.I.D. elvek:** Különös tekintettel az Single Responsibility elvére
- **Adattárolás:** CSV fájl alapú perzisztencia

## 📋 Jelenlegi funkciók
- [ ] Termék modell kialakítása (Név, Ár, Mennyiség)
- [ ] Raktár logika alapjai (Hozzáadás, Listázás)
- [ ] Fájlkezelés (Mentés/Betöltés)
- [ ] Hibakezelés (Exception handling)
